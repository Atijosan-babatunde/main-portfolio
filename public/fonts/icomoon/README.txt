This folder is intentionally left empty for now.

The site currently uses a Unicode-based fallback (see
public/css/icomoon.css) so it runs without these files.

To restore your original custom icon font, copy these files
from your old project's fonts/icomoon/ folder into this folder:
  icomoon.eot
  icomoon.svg
  icomoon.ttf
  icomoon.woff

Then replace public/css/icomoon.css with your old project's
css/icomoon.css.
