This folder is intentionally left empty for now.

The site currently uses a Unicode fallback for the mobile menu
icon (see public/css/open-iconic-bootstrap.min.css) so it runs
without these files.

To restore the original icon set, copy these files from your
old project's fonts/open-iconic/ folder into this folder:
  open-iconic.eot
  open-iconic.otf
  open-iconic.svg
  open-iconic.ttf
  open-iconic.woff

Then replace public/css/open-iconic-bootstrap.min.css with your
old project's css/open-iconic-bootstrap.min.css.
